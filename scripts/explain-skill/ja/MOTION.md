# 3Blue1Brown風の動き

ページの図は、3Blue1Brown（3b1b）の動画のように動きます。グラント・サンダーソンは、自作のアニメーションライブラリ Manim でその動画を作っています。かっこの中の名前は Manim のアニメーションの種類です（docs.manim.community の「Animations」）。実際の例を調べられます。

大切な考え方：図は1つの続いた場面です。見ている間に、ものが形を変え、動き、新しいラベルを得ます。目は1つ1つのものを最初から最後まで追えるので、見失いません。

## ルール

1. **1つの場面で、スライドにしない。** 新しい手順は、すでにある図を変えます。別の図に切りかえたり、フェードしたりしません。
2. **ものは同じものであり続ける。** 「リクエスト」の箱が手順2と手順3にあるなら、それは同じ要素です。新しい形へ、動き、大きくなり、形を変えます（transform）。各要素には、手順をまたいで同じ id を付けます。
3. **変わるラベルは、共通の部分を残す。** 「コンテキスト」が「コンテキスト＋ツールの結果」になるとき、「コンテキスト」は新しい場所へすべり、「＋ツールの結果」だけが描かれます（transform_matching_parts）。
4. **新しいものは描かれて現れる。** 輪郭が線として描かれ、次に塗りが現れます。文字は1文字ずつ書かれます（creation）。
5. **色はページ全体で同じ意味を持つ。** 図である用語に色を付けたら、説明、問いのカード、用語集もその色を使います。藍色は流れとリクエスト、黄土色はレスポンスです。
6. **カメラは細部へ動く。** 図の一部に寄って中身を見せ、また全体へ引きます。SVG では `viewBox` を動かします。
7. **生きた値が図を動かす。** 数やスライダーが変わると、図が毎フレームそれに従います（numbers、updaters）。たとえば、コンテキストウィンドウが埋まり、コストの棒がのび、トークン数が回ります。「前提を1つ変える」確かめに使います。
8. **矢印だけでなく、動きで指す。** 1回だけ脈打たせる（indication）、まわりに線を引く、ほかを30%ほどまで暗くする。
9. **グループはずらして動かす。** グループのメンバーは、動く時間の0.1〜0.2ずつずらして順に始めます（composition）。
10. **止まって考えさせる。** 答えを見せる前に、ページは問いを出し、図は止まります。読み手が予想します。そのあとで図が動きます。
11. **先に1つの例、次にルール。** 最初に本当の数で1つの例を見せ、そのあとで一般の形を見せます。

## 時間

- 教えるための変化（transform、カメラの移動）は約1秒で、なめらかに加速・減速します。Manim の標準の時間も1秒です。
- 変化のあとは1〜2秒止めて、読み手が新しい状態を読めるようにします。
- 図全体は約1.5〜2秒で描かれます。各部分は0.8秒で、45ミリ秒ずつずれて始まります。図の上の端が画面の高さの約60%を過ぎたときに始まります。2026年10月4日のテストで両方を試しました。1部分1秒・70ミリ秒ずつでは、遅すぎて見ていられませんでした。0.55秒・28ミリ秒で早く始めると、読み手が着く前に終わっていました。
- 画面の部品（ボタンなど）の動きは速いまま（約150〜250ミリ秒）です。ゆっくりした3b1bの時間は、教える内容だけに使います。

## 作り方

- **ページ。** 各手順に、v1 のデザインの図が1つずつあります。`templates/page.html` のエンジンは、図が画面に入ったときに描き（ルール4）、主な矢印の流れを一度に1つだけ動かします。`data-script` の場面で、カメラの移動や状態の変化を足します（ルール2、3、6）。[PAGE.md](PAGE.md) を見てください。
- **React。** motion/react では、`layoutId` と `layout` で手順をまたいで同じものを保ちます。`pathLength` で線を描き、SVG の `viewBox` への `animate` でカメラを動かします。`useMotionValue` と `useTransform` で生きた値を作ります。形を変えるときは、両方の形で点の数をそろえます。
- **本当の数学**（グラフ、数式、図形）。テーマに必要なら、Manim Community で場面を描き、動画として埋め込みます。Manim を入れる前にユーザーに聞きます。
- **動きを減らす設定。** 各手順の最後の状態を見せ、色と順番はそのままにします。

## 渡す前のチェック

- ページを手順ごとに見ます。2つの手順にある要素は、動くか変わるかします。消えてまた現れてはいけません。
- 色の付いた用語は、どこでも同じ色です。
