# shadcn/ui の構造を v1 の色で

説明ページは、shadcn/ui のすっきりした画面の構造を使います。見た目そのものは「How does CCFT work?」バージョン1から来ています。つまり、shadcn の構造を使い、v1 の色とフォントで埋めます。

出典（2026年10月3日に確認）：
- トークンの一覧とルールは `ui.shadcn.com/docs/theming`（テキスト版は `ui.shadcn.com/docs/theming.md`）から。
- 部品の構造は `github.com/shadcn-ui/ui` の `apps/v4/registry/new-york-v4/ui/<名前>.tsx` から。プロジェクトは MIT ライセンスです。ここに書いた細部がまちがって見えたら、そのファイルをもう一度取り寄せます。

動く例は [templates/page.html](templates/page.html) です。

## トークン：名前は shadcn、値は v1

面のトークンには、その上の文字のための `-foreground` トークンが対になっています。画面の色にはすべてトークンを使い、ダークモードは同じトークンを上書きして作ります。

| トークン | ライト | ダーク | 使い道 |
|---|---|---|---|
| `--background` / `--foreground` | `#f0f2f7` / `#16161f` | `#13141b` / `#eceef6` | ページと本文 |
| `--card` | `#fdfdfd` | `#1c1d27` | カード |
| `--border` | `#d9dbe6` | `#2e3040` | カードの縁と線 |
| `--muted-foreground` | `#666a7c` | `#9ba0b5` | 説明と注 |
| `--primary` / `--primary-foreground` | `#4f50e7` / `#ffffff` | `#5557ee` / `#ffffff` | 主なボタン、押されたトグル、藍色のブロック |
| `--accent` | `#e2e2f4` | `#262846` | トグルの溝、枠、控えめな塗り |
| `--ring` | `#4f50e7` | `#8e8fff` | フォーカスの輪 |
| `--acc` / `--och` / `--line` | `#4f50e7` / `#dbad36` / `#c9cbd8` | `#8e8fff` / `#e4b84a` / `#3a3c50` | 流れとリクエスト、レスポンス、控えめな線 |

フォント：文字はすべて Figtree（400〜900）、日本語は Noto Sans JP、コードは JetBrains Mono です。これは v1 のフォントなので、shadcn の Geist には変えません。

## shadcn から取ったルール

1. 意味の対：面とその上の文字は、いつもトークンの対で使います。
2. 角の丸みは `--radius`（0.75rem）の1つの目盛りから。カードはその1.4倍。トグルとボタンは v1 と同じく丸い形です。
3. フォーカスできる部品は、`--ring` の50%で3pxの輪を見せます。
4. トグルのグループは `aria-pressed` を使います。押された項目は `--primary` と `--primary-foreground` になります。
5. ボタンの主な種類は1つ（`--primary` で塗る）と、無効な状態（不透明度50%）です。
6. 余白は1つの目盛りから取ります。字下げは目で合わせず、構造で決めます。
7. 色は意味（流れ、レスポンス、コスト）を運びます。それ以外は中立の色にします。
8. ライトとダークは、どちらも同じトークンで動きます。両方を試します。
