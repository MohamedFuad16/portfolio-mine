# 説明ページ

ページは、そのテーマを何も知らない人に、大きな図と少ない言葉で説明します。デザインは「How does CCFT work?」バージョン1のもので、フォント、色、ロボットのアイコン、流れ図を使います。その上で、図は3Blue1Brown風に動き（[MOTION.md](MOTION.md)）、言葉は [WRITING.md](WRITING.md) に従い、操作部品は shadcn の構造に従います（[SHADCN.md](SHADCN.md)）。

[templates/page.html](templates/page.html) から始めます。このデザインで作った、テスト済みの完成したページです。中身を入れかえ、トークン、記号、エンジンはそのまま使います。完成したページは、1つで完結したHTMLファイルとして渡します。Claude では Artifact として公開することもできます。

## 形（v1 から）

- **見出しは問いにします。** Figtree 900 と Noto Sans JP 900 で書きます（「CCFTはどう動く？」）。そのあとに、太字をいくつか入れた2〜3文のリードを置きます。
- **番号つきの手順。** 各手順には、大きな藍色の番号、短い題、図が1つ入ったカード、2文までの説明を置きます。
- **事実は図が運びます。** 図は記号（ロボット、ディスク、ウィンドウ、人、時計、鍵、封筒、キー）の線画です。主役は藍色のブロックにし、矢印はまっすぐ引いて上に動詞を書きます。飾るだけの図は消します。
- **順番**：部品は何か、どう動くか（1つの動きに1手順）、何がうまくいかないか・何にコストがかかるか、そして確かめ。
- **確かめ**（番号が「？」の手順）は、問いのカード1枚です。読み手は2〜4枚の答えのカードから1枚を選び、「答えを確かめる」を押します。選ぶまでボタンは薄く、「先に答えを選んでください」と表示します。確かめたあと、正しいカードは緑に、まちがったカードはオレンジになります。バッジに「正解」か「惜しい」と出て、図が描かれます。最後に、トグルで前提を1つ変え、新しい結果を見せます。スクリプトの `ANSWER` と `VERDICT`、各答えカードの `data-guess` を設定します。
- **用語集**（「このページの言葉」）は最後に置きます。各用語に、やさしい説明を1行付けます。言葉は文章の返答と同じにします。

## エンジン（そのまま使う）

- 図は、上の端が画面の高さのおよそ60%を過ぎたときに自分で描かれます。読み手はそれを見ています。輪郭が描かれ、塗りが現れ、文字がくっきりし、矢印の先が出ます。順番は SVG の要素の順番なので、教える順に並べます。
- クラス `ar a` の矢印は主な流れです。そのカードがいちばんよく見えている間、点が矢印の上を進みます。`ar a two` の矢印はリクエストとレスポンスです。藍色の点が出ていき、黄土色の点が戻ってきます。流れを動かすカードは、一度に1枚だけです。
- `data-script="<名前>"` のある図は、描かれたあとに `SCRIPTS` の場面を1回だけ動かします。テンプレートには `rebuild` があります。カメラがコンテキストウィンドウに寄り、線を消して描き直し、引いて戻ります。新しい場面は `camera`、`tween`、`wait` で書きます。
- 動きを減らす設定のときは、どの図も最後の状態をすぐに見せます。

## 渡す前のテスト

- デスクトップの幅と 375 px で、ライトとダークの両方（`<html>` の `data-theme`）で、すべての手順をスクロールして見ます。
- 375 px で、ページの幅が画面の幅とちょうど同じです（`scrollWidth` が `innerWidth` と等しい）。幅の広い図は、v1 と同じくカードの中でスクロールします。
- どの図でも、カメラが寄ったときも、ラベルが図形やほかのラベルに触れていません。ページで `scripts/overlap.js` を実行します（隠れた図は先に表示します）。空のリストが返れば合格です。日本語のラベルは英語より幅が変わるので、特に確かめます。
- 確かめが動きます：予想、判定、図、そして値を変えるトグル。
- コンソールにエラーがありません。ページの言葉にもチェックを実行します。
- プレビュー画面によっては、ローカルのファイルを開けません。フォルダを HTTP で配信します（例：`python3 -m http.server`）。隠れたタブはフレームを描かないので、図が描かれません。テストが止まったら、見えているウィンドウか headless Chrome で実行します。
