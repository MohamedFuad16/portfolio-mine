# Conventions

- Keep UI source in `src/`.
- Keep static public assets in `public/assets/` or `public/resume/`.
- Prefer small presentational components in `src/main.jsx` unless the file becomes hard to scan.
- Use CSS classes in `src/styles.css`; avoid inline styles except for small per-item CSS variables.
- Maintain the compact dark reference style: centered narrow column, dashed borders, low-radius controls, restrained motion.
