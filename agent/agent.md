  data / portfolio content          → agent/data.md
  where to put a file / style       → agent/conventions.md
  tests / verification              → agent/tests.md
  bug / gotcha / known issue        → agent/errors.md
  secrets / env keys                → agent/secrets.md
  why something was decided         → agent/decisions.md
  what changed / current state      → agent/state.md
